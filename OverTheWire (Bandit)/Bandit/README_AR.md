## 🛠️ الحلول العملية خطوة بخطوة (0 إلى 16)

### المستوى 0 → 1: الاتصال الأول بـ SSH
الاتصال بسيرفر اللعبة:
```bash
ssh bandit0@bandit.labs.overthewire.org -p 2220
```
كلمة السر: `bandit0`
قراءة كلمة سر المستوى التالي:
```bash
cat readme
```

---

### المستوى 1 → 2: الملفات التي تبدأ بعلامة الشرطة (-)
عندما يبدأ اسم الملف بـ `-` يظن موجه الأوامر Bash أنه خيار (Flag) للأمر. لتفادي ذلك نحدد المسار النسبي:
```bash
cat ./-
```

---

### المستوى 2 → 3: أسماء الملفات التي تحتوي على مسافات
الملف اسمه `spaces in this filename`. لقراءته نستخدم علامات التنصيص أو الـ Backslash:
```bash
cat "spaces in this filename"
```

---

### المستوى 3 → 4: الملفات المخفية (Hidden Files)
الملفات المخفية في لينكس تبدأ بنقطة `.`. لعرضها نستخدم خيار `-a`:
```bash
cd inhere
ls -la
cat .hidden
```

---

### المستوى 4 → 5: معرفة نوع الملف المقروء (File Command)
المجلد يحتوي على ملفات باينري ونصوص. نستخدم أمر `file` لمعرفة الملف النصي القابل للقراءة:
```bash
file inhere/*
cat inhere/-file07
```

---

### المستوى 5 → 6: البحث بالحجم والمواصفات (Find)
البحث عن ملف حجمه 1033 بايت بالضبط وغير قابل للتنفيذ:
```bash
find inhere -type f -size 1033c ! -executable
cat inhere/maybehere07/.file2
```

---

### المستوى 6 → 7: البحث على مستوى النظام بالمستخدم والمجموعة
البحث في كامل النظام عن ملف يملكه المستخدم `bandit7` والمجموعة `bandit6` بحجم 33 بايت:
```bash
find / -user bandit7 -group bandit6 -size 33c 2>/dev/null
cat /var/lib/dpkg/info/bandit7.password
```

---

### المستوى 7 → 8: البحث عن كلمة معينة (Grep)
استخراج السطر الذي يحتوي على كلمة `millionth`:
```bash
grep "millionth" data.txt
```

---

### المستوى 8 → 9: استخراج السطور الفريدة (Sort & Uniq)
البحث عن السطر الوحيد الذي لم يتكرر:
```bash
sort data.txt | uniq -u
```

---

### المستوى 9 → 10: قراءة النصوص من الملفات الثنائية (Strings)
استخراج النصوص المقروءة التي تسبقها علامات `=`:
```bash
strings data.txt | grep "==="
```

---

### المستوى 10 → 11: فك تشفير Base64
```bash
base64 -d data.txt
```

---

### المستوى 11 → 12: فك تشفير ROT13
استبدال الأحرف المزاحة بـ 13 خانة باستخدام أمر `tr`:
```bash
tr 'A-Za-z' 'N-ZA-Mn-za-m' < data.txt
```

---

### المستوى 12 → 13: فك الطبقات المتعددة لضغط الملفات
الملف عبارة عن Hex Dump. نقوم بتحويله ثم فك طبقات الضغط (`gzip`, `bzip2`, `tar`) بالترتيب:
```bash
mkdir /tmp/bandit12 && cd /tmp/bandit12
cp ~/data.txt .
xxd -r data.txt uncompressed
file uncompressed
# تكرار الفك بحسب نوع كل أرشيف حتى الوصول للنص الصريح
```

---

### المستوى 13 → 14: تسجيل الدخول بمفتاح SSH خاص
استخدام المفتاح الخاص للدخول إلى `bandit14` على localhost:
```bash
ssh -i sshkey.private bandit14@localhost -p 2220
cat /etc/bandit_pass/bandit14
```

---

### المستوى 14 → 15: إرسال البيانات عبر منفذ شبكي (Netcat)
إرسال كلمة سر المستوى 14 إلى المنفذ `30000`:
```bash
echo "fGrHPx402xGC7U7rXKDaxiWFTOiF0ENq" | nc localhost 30000
```

---

### المستوى 15 → 16: الاتصال الشبكي المشفر عبر SSL/TLS
إرسال كلمة السر لمنفذ مشفر بـ SSL باستخدام أداة `openssl s_client`:
```bash
openssl s_client -connect localhost:30001 -quiet
```

---

### المستوى 16 → 17: فحص المنافذ واستخراج مفتاح الدخول
1. فحص المنافذ من 31000 إلى 32000 باستخدام Nmap لمعرفة المنفذ الذي يدعم SSL.
2. الاتصال بالمنفذ المكتشف وإرسال كلمة السر عبر `openssl s_client`.
3. الخادم يرجع **المفتاح الخاص (RSA Private Key)** للمستخدم `bandit17`.
4. حفظ المفتاح وضبط أذوناته (`chmod 600`) والاتصال بالمستوى التالي:
```bash
ssh -i key bandit17@localhost -p 2220
```

## 🛡️ نصائح وتوجيهات هامة للمبتدئين
1. **قوة سطر الأوامر (Pipelines):** ميزة لينكس العظمى هي ربط الأوامر البسيطة بـ `|` لتنفيذ مهام استخراج وتحليل معقدة في سطر واحد.
2. **إخفاء أخطاء الصلاحيات:** استخدام `2>/dev/null` لتجاهل رسائل "Permission Denied" أثناء البحث في مسار الـ Root.
3. **الفرق بين الترميز والتشفير:** التشفير (Encryption) يحتاج لمفتاح سري كـ SSH و SSL، بينما الترميز (Encoding) كـ Base64 أو Hex هو مجرد تمثيل للبيانات يمكن لأي شخص استرجاعه.
