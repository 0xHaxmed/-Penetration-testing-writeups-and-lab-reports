## 📋 بطاقة الهدف والمعلومات العامة

| العنصر | التفاصيل |
| :--- | :--- |
| **اسم الماشين** | Metasploitable 2 (منصة VulnHub / Rapid7) |
| **نظام التشغيل** | Ubuntu Linux 8.04 LTS |
| **نوع التقييم** | تدقيق أمني واختراق شامل لأكثر من 15 خدمة شبكية |
| **أبرز الثغرات** | باك دور vsftpd، ثغرة Samba usermap، باك دور UnrealIRCd، نشر شل WAR في Tomcat |

---

## 🔍 مصفوفة استغلال الخدمات في التقرير

| الخدمة | المنفذ | الثغرة / مسار الاستغلال | رقم CVE | الصلاحية |
| :--- | :--- | :--- | :--- | :--- |
| **vsftpd** | `21/tcp` | ثغرة الباك دور الشهيرة (Smiley Face `:)`) | CVE-2011-2523 | `root` |
| **Samba** | `139/445` | تنفيذ أوامر عبر `usermap script` | CVE-2007-2447 | `root` |
| **UnrealIRCd** | `6667/tcp` | شل عكسي عبر باك دور في الكود المصدري | CVE-2010-2075 | `root` |
| **distcc** | `3632/tcp` | تنفيذ أوامر بدون مصادقة | CVE-2004-2687 | `daemon` |
| **Tomcat** | `8180/tcp` | بيانات افتراضية `tomcat:tomcat` ورفع شل WAR | CWE-522 | `tomcat` |
| **Ingreslock** | `1524/tcp` | شل مفتوح ومباشر بدون باسورد | N/A | `root` |
