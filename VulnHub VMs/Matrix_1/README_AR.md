## 🎯 مسار الهجوم
1. **الاستطلاع:** فحص Nmap أظهر المنفذ 22 (SSH) والمنفذ 80 (Apache).
2. **فحص الويب وفك التشفير:** عند فحص السورس كود لموقع Matrix، وُجدت تعليقات ونصوص مشفرة برمز لغة البرمجة غير التقليدية **Brainfuck** (رموز `+-><[]`).
3. **استخراج البيانات:** بفك تشفير الكود، تم استخراج بيانات تسجيل الدخول وتجاوز المسارات المضللة.
4. **تصعيد الصلاحيات:** تسجيل الدخول على النظام والبحث عن ملفات SUID وأذونات Sudo للوصول إلى صلاحيات الجذر الكاملة (`root`).
