| العنصر | التفاصيل |
| :--- | :--- |
| **اسم الماشين** | Vulnix (منصة VulnHub) |
| **آي بي الهدف** | `192.168.1.132` |
| **مستوى الصعوبة** | متوسط (Intermediate) |
| **المفاهيم الأساسية** | ثغرات مشاركة ملفات NFS، انتحال هوية المستخدم (UID Spoofing)، استغلال `sudoedit` لملف `/etc/exports` |

## 🎯 مسار الهجوم
1. **استطلاع NFS:** أظهر أمر `showmount -e` أن مسار `/home/vulnix` مفتوح للجميع عبر شبكة NFS.
2. **انتحال الـ UID:** فحص تصريحات المجلد أظهر أن مالك المجلد يحمل UID برقم `2008`. قمنا بإنشاء مستخدم على كالي بنفس الرقم لنتمكن من الكتابة في المجلد وزرع مفتاح SSH العام داخل `authorized_keys`.
3. **الدخول كمستخدم:** الاتصال عبر SSH كمستخدم `vulnix` بدون باسورد.
4. **تصعيد الصلاحيات عبر sudoedit:** المستخدم لديه تصريح تعديل ملف `/etc/exports`. قمنا بإضافة أمر تصدير مسار الجذر `/` مع خاصية `no_root_squash`.
5. **السيطرة بـ SUID:** قمنا بعمل Mount لمسار الـ Root من جهاز كالي، ونسخنا مترجم أوامر Bash مع وضع صلاحية `SUID`، ثم تشغيله على الماشين للوصول الفوري إلى مستخدم الجذر `root`.
