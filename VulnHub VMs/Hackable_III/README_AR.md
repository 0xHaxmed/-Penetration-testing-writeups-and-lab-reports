## 🛠️ خطوات الهجوم العملية
1. **تقنية Port Knocking:** عند فحص السيرفر، كان منفذ SSH مغلقاً، ومن خلال استخراج تسلسل الأرقام السري من الموقع، تم استخدام أداة `knock` لإرسال حزم الاتصال لفتح المنفذ ديناميكياً:
   ```bash
   knock 10.10.10.6 7000 8000 9000
   ```
2. **تسجيل الدخول:** بعد فتح المنفذ 22، تم تسجيل الدخول كمستخدم عادي.
3. **تصعيد الصلاحيات:** اكتشاف ملف مهام مجدولة (`/etc/crontab`) يشغله مستخدم Root دورياً ويسمح للمستخدمين بتعديله. قمنا بحقن أمر منح صلاحية `SUID` لمترجم الأوامر `/bin/bash` والوصول لأعلى صلاحية في النظام.
