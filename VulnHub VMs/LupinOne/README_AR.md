## 📋 بطاقة الهدف والمعلومات العامة

| العنصر | التفاصيل |
| :--- | :--- |
| **اسم الماشين** | LupinOne (منصة VulnHub) |
| **مستوى الصعوبة** | متوسط (Intermediate) |
| **المفاهيم الأساسية** | فحص المسارات المخفية (Fuzzing)، فك تشفير Fastcipher، اعتراض مكتبات بايثون (Library Hijacking)، استغلال Sudo Pip |

## 🎯 مسار الهجوم
1. **اكتشاف المسار السري:** عبر أداة `ffuf` تم العثور على المسار `~secret` الذي يحتوي على مفتاح SSH مشفر بـ Fastcipher.
2. **كسر تشفير المفتاح:** بعد فك التشفير، تم استخراج الهاش وكسره بـ `John the Ripper` والدخول بحساب `icex64`.
3. **اعتراض مكتبات بايثون (Library Hijacking):** وجدنا تصريحاً لتشغيل سكريبت بايثون كالمستخدم `arsene`. السكريبت يستدعي مكتبة `webbrowser`. قمنا بإنشاء ملف خبيث بنفس الاسم يحقن أوامر Bash، ليتم استدعاؤه والتحول لـ `arsene`.
4. **الوصول للـ Root عبر Pip:** المستخدم `arsene` يمتلك تصريح `sudo pip`. بالرجوع لموقع GTFOBins، تم تشغيل كود تثبيت محلي يمنح شل فوري بصلاحيات `root`.
